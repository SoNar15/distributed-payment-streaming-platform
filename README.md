# Distributed Real-Time Payment Streaming Platform

A distributed event-driven payment processing platform built using Kafka, Spark Structured Streaming, and lakehouse architecture concepts.

## Architecture

Payment Generator
    ↓
Kafka
    ↓
Spark Structured Streaming
    ↓
Bronze Layer
    ↓
Silver Layer

## Tech Stack

- Python
- Kafka
- Spark Structured Streaming
- Delta Lake
- AWS S3 (planned)

## Goal

This project simulates real-world financial event processing systems used in modern banking and payment infrastructure.
